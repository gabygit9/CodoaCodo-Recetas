# Proyecto Recetas

Bienvenido a **CodoaCodo-Recetas**, un proyecto dedicado a compartir deliciosas recetas de cocina. Aquí encontrarás una variedad de recetas para disfrutar en casa y sorprender a tus seres queridos.

## Recetas Incluidas

1. **Brownie**  
   ¡Disfruta de un rico brownie de chocolate! Perfecto para la hora del té o como un postre especial.

2. **Muffins de Banana y Chocolate**  
   Estas muffins son suaves y esponjosas, ideales para el desayuno o una merienda.

3. **Tacos Campechanos**  
   Deliciosos tacos llenos de sabor, ideales para cualquier ocasión.

4. **Tostada Jerezana**  
   Un aperitivo clásico que no puede faltar en tus reuniones familiares.

## Estructura del Proyecto

El proyecto se organiza de la siguiente manera:

```
CodoaCodo-Recetas/
│
├── index.html        # Página principal del sitio
├── styles.css        # Estilos para la página
├── scripts.js        # Archivos JavaScript (si aplica)
├── recetas/
│   ├── brownie.html  # Receta de brownie
│   ├── muffins.html   # Receta de muffins de banana y chocolate
│   ├── tacos.html    # Receta de tacos campechanos
│   └── tostada.html  # Receta de tostada jerezana
└── img/              # Carpeta para imágenes
    ├── brownie.jpg
    ├── muffins.jpg
    ├── tacos.jpg
    └── tostada.jpg
```
